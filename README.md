# Переход к хаосу через каскад бифуркаций удвоения периода в обобщённом отображении параболы

## Тема

Исследование универсальности и скейлинговых свойств перехода к хаосу в обобщённом одномерном отображении:

$$x_{n+1} = 1 - \mu \cdot |x_n|^z$$

где $\mu \in [0, 2]$ — параметр управления, $z \geq 1.5$ — порядок экстремума в критической точке $x = 0$.

При $z = 2$ отображение сводится к классической параболе ($f(x) = 1 - \mu x^2$), для которой Фейгенбаум (1978) обнаружил универсальные константы каскада удвоения периода.

## Что вычисляется

- **Бифуркационная диаграмма** — зависимость аттрактора от $\mu$
- **Паутинная диаграмма** — графическое итерирование $f(x)$ vs $y = x$
- **Показатель Ляпунова** — $\lambda(\mu) = \lim_{N \to \infty} \frac{1}{N} \sum_{n=0}^{N-1} \ln |f'(x_n)|$
- **Точки бифуркаций** $\mu_1, \mu_2, \ldots$ — грубый скан + бисекция
- **Константы Фейгенбаума**:
  - $\delta_n = \frac{\mu_n - \mu_{n-1}}{\mu_{n+1} - \mu_n} \to \delta(z)$ (для $z=2$: $\delta = 4.6692016\ldots$)
  - $\alpha_n$ через отношение расстояний суперустойчивых орбит $\to \alpha(z)$ (для $z=2$: $\alpha = 2.5029079\ldots$)
- **Скейлинг** — самоподобие бифуркационной диаграммы при последовательных увеличениях
- **Зависимость $\delta(z)$ и $\alpha(z)$** — обобщение на произвольный порядок экстремума

## Структура проекта

| Файл | Описание |
|------|----------|
| `core.py` | Вычислительное ядро (NumPy, векторизовано). Все именованные константы вынесены в начало файла |
| `gui.py` | Интерактивный GUI на matplotlib с 6 вкладками и слайдерами по $z$ и $\mu$ |
| `main.py` | Точка входа для запуска GUI |
| `export_figures.py` | Генерация PNG-графиков (300 dpi) для курсовой, без запуска GUI |
| `export_tables.py` | Генерация CSV-таблиц с точками бифуркаций, $\delta_n$, $\alpha_n$ и сводной таблицей |
| `requirements.txt` | Зависимости: `numpy`, `matplotlib` |

## Запуск

### Установка зависимостей

```bash
pip install -r requirements.txt
```

Для GUI также необходим `tkinter` (обычно входит в стандартную поставку Python; на Ubuntu/Debian: `sudo apt install python3-tk`).

### Интерактивный GUI

```bash
python main.py
```

6 вкладок: Бифуркация, Паутина, Ляпунов, Фейгенбаум, Скейлинг, Динамика.  
Слайдеры позволяют менять $z$ и $\mu$ в реальном времени.  
Кнопка "Экспорт CSV" на вкладке Фейгенбаум сохраняет таблицу в текущую директорию.

### Экспорт графиков

```bash
python export_figures.py
```

Сохраняет в папку `figures/` PNG-файлы для $z \in \{2.0, 2.1, 2.2, 2.3\}$:
- Бифуркационные диаграммы (полный вид)
- Увеличенные фрагменты бифуркационного дерева вблизи точки накопления (3 уровня зума, с отмеченными точками бифуркаций)
- Показатели Ляпунова
- Скейлинг (самоподобие)
- Сходимость $\delta_n$ и $\alpha_n$ (каждая точка подписана значением — видно процесс: 4→5→4.6→4.67→...)
- Зависимость констант от $z$ (плотная сетка $z \in [2.0, 4.0]$ с шагом 0.1)

### Экспорт таблиц

```bash
python export_tables.py
```

Сохраняет в папку `tables/` CSV-файлы для $z \in \{2.0, 2.1, 2.2, 2.3\}$:
- `convergence_z{z}.csv` — подробная таблица сходимости: n, период $2^n$, $\mu_n$, $\Delta\mu_n$, $\delta_n$, $\alpha_n$ (виден весь процесс: $\delta_1$, $\delta_2$, ..., предел)
- `summary_delta_alpha_vs_z.csv` — сводная таблица с эталонными значениями и % отклонения
